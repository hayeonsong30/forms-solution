## 1. 화면 개요

- **화면 ID**: `FRM-02`
- **화면 이름**: 양식 편집기
- **메뉴 경로**: 양식 관리 > 행 클릭 / 빈 양식 업로드 / 복제
- **대상 사용자**: 양식 필드와 인식 옵션을 설정하는 내부 담당자
- **비즈니스 목적**: PDF 위에 입력 필드를 배치하고 데이터 키와 인식 규칙을 정의하여 인쇄 가능한 양식을 만든다.
- **진입 경로**: `/editor/{templateId}`

> Excel 연동은 `FRM-03_DataTemplate.md`에서 별도로 다룬다. 본 문서에서는 진입 버튼만 기술한다.

---

## 2. 주요 사용자 흐름 (Happy Path)

1. FRM-01에서 신규 양식을 생성하거나 기존 양식 선택
2. PDF 파일 업로드
3. 필드 유형을 선택하여 PDF 위에 배치
4. 필드명, 데이터 키, 유형별 인식 옵션 설정
5. 필요 시 여러 체크 필드를 하나의 선택 필드로 병합
6. AI 자동 추천으로 필드 후보 생성 후 채택 또는 거부
7. 데이터 테스트에서 출력 구조 확인
8. 구조 검사 통과 후 상태를 `인쇄 가능`으로 변경

> 표 형태 데이터(품목 목록 등)는 개별 필드를 만들고 데이터 키에 `.01`, `.02`처럼 순번을 붙여 표현한다. 자세한 내용은 §4.4a 참고.

## 3. 화면 구성

### 3.1 헤더 1행 — 양식 정보·상태

- `[← 뒤로]` 클릭 시 양식 관리 목록(FRM-01)으로 이동
- 양식명 클릭 시 인라인 편집
  - Enter 또는 포커스 이탈: 저장
  - Escape: 수정 취소
  - 읽기 전용 상태: 편집 불가(버튼 비활성), 연필 아이콘(`✎`) 미노출
- 저장 상태 표시
  - 저장 전: `자동 저장`
  - 저장 중: `저장 중…`
  - 저장 완료: `{시:분:초}에 저장됨`
  - 저장 실패: `저장 실패 — 저장 버튼을 눌러 다시 확인하세요`
- `[💾 저장]`: 서버 데이터를 다시 조회하여 화면에 반영(신규 데이터를 만들어 저장하는 버튼이 아니라, 개별 변경마다 이미 자동 저장된 최신 상태를 다시 불러와 확인하는 용도)
- `[▷ 데이터 테스트]`: 데이터 테스트 팝업 노출
- `[📊 Data Template]`: Excel 템플릿 설정 팝업 노출
- `[🖨 인쇄 부수]`: 인쇄 부수 설정 팝오버 노출
  - 설정 부수가 2부 이상이면 버튼에 숫자 배지 표시
  - 읽기 전용 상태에서는 비활성
- 상태 세그먼트: `편집 중` / `인쇄 가능`
- `[⧉ 복제해서 편집]`
  - 인쇄 이력(`printedCount > 0`)이 있는 양식에만 노출
  - 복제 중에는 `복제 중…`으로 표시하고 버튼 비활성

### 3.2 인쇄 부수 팝오버

- 인쇄 예정 부수 입력, 최소 1부
- 필요 SOBP 수를 `페이지 수 × 부수`로 계산
- 안내 문구: `{페이지 수}페이지 × {부수}부 = SOBP {합계}개 필요`
- `[저장]`: `printCopies` 저장 후 팝오버 닫기
- `[닫기]`: 변경 없이 팝오버 닫기
- 양식이 읽기 전용이 되면 부수 변경 불가

### 3.3 헤더 2행 — 편집 도구

**도구:**

- `[⛶ 선택]`: 필드 선택·이동·크기 조절
- `[✋ 이동]`: 캔버스 패닝

**실행 내역:**

- `[↩ 실행 취소]`: Cmd/Ctrl+Z
- `[↪ 다시 실행]`: Cmd/Ctrl+Shift+Z
- 실행 가능한 내역이 없으면 해당 버튼 비활성

**필드(읽기 전용 상태에서는 그룹 전체 미노출):**

- `[⧉ 복사]`: Cmd/Ctrl+C, 선택 필드 복사
- `[📋 붙여넣기]`: Cmd/Ctrl+V, 복사한 필드 붙여넣기(원본에서 14px만큼 이동해서 생성)
- `[🗑 삭제]`: Delete, 선택 필드 삭제

**화면:**

- `[-]` / `[+]`: 캔버스 축소·확대(10%p 단위, 40%~250% 범위)
- 현재 줌 비율 표시
- `[화면 맞춤]`: PDF를 작업 영역에 맞춤

**기타(읽기 전용 상태에서는 미노출):**

- `[선택 필드로 묶기 ({n})]`
  - 필드 2개 이상 선택 시에만 노출
  - 선택한 필드들을 하나의 선택(choice) 필드로 병합 — 반드시 같은 페이지 필드만 가능
- `[✦ AI 자동 추천]`
  - PDF가 없거나 분석 중이면 비활성
  - 분석 중 `AI 분석 중… (최대 2분)`으로 표시

**페이지 이동:**

- 이전/다음 페이지 버튼과 `{현재} / {전체}페이지` 표시
- 전체 페이지가 1개이면 페이지 이동 컨트롤 자체가 미노출

### 3.4 알림 배너

- **AI 필터링 안내**: 제외된 후보가 있으면 보라색 배너 표시
  - 문구: `신뢰도가 낮거나 영역이 너무 작은 후보 {n}개는 자동으로 제외했습니다.`
- **오류 안내**: 작업 실패 시 빨간색 배너 표시
- 오류는 자동으로 사라지지 않으며 다음 작업 시작 또는 다른 오류 발생 시 갱신
- 오류 배너가 있으면 AI 필터링 안내보다 우선 표시(둘 다 있으면 오류만 보임)

### 3.5 왼쪽 패널 — 필드 추가·목록

- 필드 유형: 텍스트(T) / 숫자(#) / 날짜(日) / 시간(時) / 체크(✓) / 선택(●)
- 필드 추가 방법
  - 유형 카드를 캔버스로 드래그
  - 유형 카드 클릭(선택 표시로 바뀜) 후 캔버스에서 배치 위치 클릭
- PDF가 없거나 읽기 전용이면 필드 추가 카드 전체가 비활성
- 검색창(`필드명 또는 데이터 키`)에서 필드명 또는 데이터 키로 필터링
- 구조 목록은 현재 페이지 필드/반복행만 표시하며, 필드 개수와 반복행 개수를 합산한 숫자를 헤더에 표시
- 필드 행 구성
  - 유형 아이콘, 필드명
  - AI 추천 필드(`status = suggested`): 보라색 아이콘과 `AI` 배지
  - 마우스오버 시 잠금(🔒/🔓), 표시/숨김(👁/␣), 삭제(✕) 버튼 노출
- 반복행은 별도 항목(↻ 아이콘, `Repeat` 라벨)으로 표시되고, 하위에 열 구성이 들여쓰기로 나열됨
- 필드도 반복행도 없으면 `아직 필드가 없습니다.` 표시

### 3.6 중앙 캔버스

- PDF 없음: PDF 업로드 안내 화면 표시
- PDF 있음: 렌더링된 PDF 위에 필드 박스 표시

**필드 박스 표시:**

| 상태 | 표시 |
|---|---|
| 기본 | 회색 실선 |
| AI 제안(`status = suggested`) | 보라색 점선 |
| 단일 선택 | 브랜드 색상 실선 |
| 다중 선택 | 주황색 실선 |
| 잠금 | 라벨 앞에 🔒 표시 |

반복행 영역은 청록색 테두리 박스로 표시되며, 상단에 `{그룹명} × {최대 행 수}`를 라벨로 보여준다.

**캔버스 조작:**

- 빈 영역 클릭: 선택 해제
- 빈 영역 드래그: 사각형과 겹치는 필드를 마퀴 선택으로 다중 선택
- 필드 드래그: 위치 이동(잠긴 필드는 이동 불가)
- 모서리 핸들 드래그: 크기 조절
- 다중 선택 필드 드래그: 선택 필드 전체를 동일한 거리만큼 이동
- 이동 범위: 모든 필드가 페이지 안(0~1)에 유지되도록 제한
- 방향키: 선택 필드를 0.002(정규화 좌표) 단위로 이동
- Shift+방향키: 0.01 단위로 더 크게 이동
- 선택 필드가 choice이고 옵션에 영역이 지정돼 있으면, 옵션별 판정 영역을 하늘색 점선 박스로 표시(현재 영역 지정 대상 옵션은 주황색으로 강조)

### 3.7 오른쪽 패널 — 필드 속성

- 필드도 반복행도 미선택: `필드를 선택하세요.` 표시
- 필드 선택: 필드 속성 패널 표시
- 반복행 선택: 반복행 속성 패널 표시(§4.4a)
- 읽기 전용: 패널 전체를 `pointer-events-none opacity-60`으로 흐리게 표시하고 입력 차단

**기본 정보:**

- 필드명
- 데이터 키(안내 문구: "편집 완료(인쇄 가능 전환) 전까지만 수정할 수 있습니다.")
- 데이터 유형: 텍스트 / 숫자 / 날짜 / 시간 / 체크 판정 / 선택
- 설명
- 필수 필드 여부
- 필드 잠금 시 필드명, 데이터 키, 유형 입력이 비활성화됨
- AI 추천 필드(`status = suggested`)에는 "AI가 제안한 필드입니다. 검수 후 채택하거나 거부하세요." 안내와 `[채택]` / `[거부]` 버튼이 함께 표시됨

**유형별 인식 옵션(코드의 `FieldConfig` 기준):**

| 유형 | 설정 항목 |
|---|---|
| 텍스트 | 작성 형태(한 줄/여러 줄), 인식 언어(일본어/한국어/영어/자동), 문자 정책(모든 문자/숫자 포함 문자/영숫자), 최대 길이, 공백 보존, 줄바꿈 보존(여러 줄일 때만 노출) |
| 숫자 | 숫자 형식(정수/소수), 소수 자릿수(0~6, 소수일 때만 노출), 음수 허용, 최소·최대, 단위, 천 단위 구분 허용, 빈칸 허용 |
| 날짜 | 입력 형식(자동 판별 / YYYY/MM/DD / YYYY-MM-DD / YYYY년 MM월 DD일 / MM/DD(연도 생략)), 출력 형식(YYYY-MM-DD / 원본 표기 유지) |
| 시간 | 입력 형식(자동 판별 / 24시간제 / 오전·오후 12시간제 / 시·분 분리 기입), 출력 형식(HH:mm / 원본 표기 유지) |
| 체크 | 판정 방식(체크 유무 / true·false 기호), 출력 형식(T/F로 변환 / 필기 인식 그대로), true 표시 기호, false 표시 기호(true/false 기호 방식일 때만 노출), 빈칸 처리(null / false / 필수 오류) |
| 선택 | 선택 방식(단일/다중), 충돌 정책(두 개 이상 표시되면 확인 필요 / 마지막으로 표시된 값 사용 / 처음 표시된 값 사용), CSV 방식(구분자로 한 열에 결합 / 옵션별 열 분리) |

**날짜·시간 처리 참고:**

- 입력 형식은 OCR 프롬프트의 인식 힌트로 사용
- 실제 값 해석은 공통 정규화 로직 사용
- 출력 형식은 정규화된 저장값에 반영

**체크 처리 참고:**

- true 기호: 체크(✓) · V · 동그라미(●) · 칸 채움(▪) · 사선(╱) 중 복수 선택 가능
- false 기호: 엑스(✕) · 곱하기(×) 중 복수 선택 가능(true/false 기호 방식일 때만 설정)
- 설정한 기호는 OCR 프롬프트에 전달
- 출력 형식을 `필기 인식 그대로`로 설정 시 등록된 기호와 일치하는 값만 유효 처리, 아니면 T/F로 정규화

**선택(choice) 옵션:**

- 옵션별 표시명(`labelPlaceholder: 표시명`)과 저장값(`valuePlaceholder: 저장값`) 설정
- `[캔버스에서 드래그…]`(영역 미지정 시 `+ 영역 지정`, 지정 후에는 `영역 다시 지정`) 클릭 후 캔버스에서 판정 영역 지정
- 옵션별로 `영역 지정됨` / `영역 미지정` 상태 텍스트 표시
- 옵션 추가(`+ 옵션 추가`)·삭제(`삭제`)
- `[선택 해제 (개별 체크 필드 {n}개로 복원)]` 클릭 시 개별 체크 필드로 복원(옵션이 1개 이상 있을 때만 버튼 노출)

**위치·크기:**

- X, Y, Width, Height: 0~1 정규화 좌표를 %로 입력받는 필드
- 페이지 번호
- 잠금: "잠금 (위치·유형·데이터 키 변경 방지)"
- 하단 `[필드 삭제]` 버튼 제공

### 3.8 하단 영역

- 현재 페이지 / 전체 페이지: `페이지 {p}/{전체}`
- 선택된 필드 수: `선택 {n}개` (단일 필드 또는 그룹 선택 시 1로 표시, 다중 선택 시 선택 개수)
- `정규화 좌표 (0~1)` 안내
- 표시 전용이며 별도 동작 없음

## 4. 주요 기능 및 상태

### 4.1 PDF 없음

- 조건: `hasPdf = false`
- 신규 양식의 기본 상태
- 안내 문구
  - `빈 양식 PDF를 업로드하세요`
  - `PDF를 이 영역으로 끌어다 놓거나 파일을 선택하세요. 최대 20MB.`
  - `PDF가 업로드되기 전까지 필드 추가와 AI 자동 추천은 사용할 수 없습니다.`
- 필드 추가와 AI 자동 추천 비활성
- 업로드 중: `PDF 업로드 중…`
- 업로드 성공: 서버 저장 후 1페이지부터 렌더링
- 업로드 실패: `PDF 업로드에 실패했습니다.` 표시
- 최대 크기 20MB는 서버에서도 base64 길이 기준으로 강제됨(20MB × 4/3 바이트 초과 시 거부)

### 4.2 편집 중

- 조건: `status = draft`이고 인쇄 이력(`printedCount`) 없음
- PDF와 저장된 필드를 불러와 편집 가능
- 필드가 0개이면 구조 목록에 빈 상태 표시
- 필드가 0개(반복행도 0개)인 상태에서 인쇄 가능 전환 시 검증 실패

### 4.3 필드 선택

- 캔버스 또는 왼쪽 목록에서 필드 클릭 시 선택
- 속성값 변경 시 서버에 저장(대부분 blur 시점에 PATCH, 체크박스류는 즉시 저장)
- 일반 필드: 기본 속성·인식 옵션 표시
- AI 추천 필드: 안내 배너와 `[채택]` / `[거부]` 표시
  - 채택: 상태를 `confirmed`로 변경
  - 거부: 해당 필드 삭제(거부도 삭제 로직을 그대로 타므로, choice이고 옵션이 있으면 §4.4의 복원 확인이 함께 뜬다)

### 4.4 선택 필드 병합·해제

**병합:**

- 필드 2개 이상 선택 후 `[선택 필드로 묶기]` 실행 → 필드명·선택 방식(단일/다중)을 입력하는 모달 노출
- 선택 필드가 서로 다른 페이지에 있으면 병합 실패(`같은 페이지의 필드만 묶을 수 있습니다.`)
- 성공 시 원본 필드들은 삭제되고 하나의 choice 필드 + 옵션(원래 위치를 그대로 옵션 판정 영역으로 사용)으로 변환

**해제 또는 삭제:**

- 옵션이 있는 choice 필드 삭제 시 확인창 노출: `"{필드명}"은(는) {n}개 옵션이 합쳐진 선택 필드입니다. 확인: 개별 체크 필드 {n}개로 복원 / 취소: 다음 화면에서 완전 삭제 여부 선택`
- 복원 선택: 옵션 판정 영역을 기준으로 개별 체크 필드 생성(서버가 409를 주면 "잠긴 필드는 복원할 수 없습니다.", 그 외 실패면 "옵션에 영역이 지정되지 않아 개별 필드로 복원할 수 없습니다.")
- 완전 삭제 선택: 다시 확인창(`"{필드명}"과 옵션 {n}개를 모두 삭제합니다. 계속할까요?`) 후 choice 필드와 모든 옵션 삭제
- 옵션 영역이 없으면 개별 필드 복원 불가
- 잠긴 필드는 복원·삭제 불가(`잠긴 필드는 삭제할 수 없습니다.`)

### 4.4a 반복행 (표 형태 데이터)

- 표 형태 데이터(품목 목록 등)는 텍스트/숫자 등 개별 필드를 하나씩 만들고, 그 데이터 키에 `.01`, `.02`처럼 순번을 붙여 표현한다. FRM-03(Data Template Excel)의 플레이스홀더 등록도 이 방식으로 만든 데이터 키를 그대로 쓴다.
- 기존 양식에 반복행 데이터(DB의 `RepeatGroupDTO`)가 있으면 조회·편집·해제가 가능하다: 그룹명·최대 행 수·빈 행 처리 편집, 열 병합/해제, 행별 고정값, `[반복행 해제 (첫 행 필드로 되돌리기)]`로 그룹 삭제.

### 4.5 AI 자동 추천

- 현재 페이지를 1600px 폭 PNG로 변환하여 분석 API(`/ai-detection`)에 전달
- 신뢰도(`confidence`) **0.4 미만** 또는 영역 면적(`box.w × box.h`) **0.0003 미만**인 후보는 자동 제외(좌표가 0~1 범위를 벗어난 후보도 함께 제외)
- 통과한 후보는 `source = ai`, `status = suggested`로 필드 생성되어 캔버스에 추가
- 사용자가 필드별로 채택 또는 거부
- PDF가 없거나 양식이 draft가 아니면 API 자체가 409로 거부(버튼은 이미 비활성 상태이므로 정상 흐름에서는 발생하지 않음)

**실패 메시지:**

- Gemini 분석 실패(`AI_DETECTION_FAILED`): `AI 분석에 실패했습니다. 잠시 후 다시 시도해주세요.`
- 그 외 오류: `AI 자동 추천에 실패했습니다. 잠시 후 다시 시도해주세요.`

### 4.6 데이터 테스트

- 실제 입력값 없이 필드 순서와 데이터 키 확인
- CSV·JSON 출력 구조 미리보기
- choice 다중 선택의 CSV 정책이 옵션별 열 분리(`one_column_per_option`)인 경우 `{dataKey}_{storedValue}` 형식의 열로 표시
- 읽기 전용 팝업이며 데이터 저장 기능 없음

### 4.7 인쇄 가능 전환

- `[인쇄 가능]` 클릭 시 `/activate` 호출로 구조 검사 실행
- 검사 통과: `status = printable`로 변경 후 편집 잠금
- 검사 실패: `draft` 유지, 오류 배너 표시

**검사 항목(`validateFields`, 필드 + 반복행 공통 적용):**

- 필드·반복행 합계 1개 이상 존재
- 데이터 키 중복 여부(필드·반복행 통틀어 동일 페이지 여부와 무관하게 검사)
- 같은 페이지 내 영역 겹침 여부(필드·반복행 박스 기준)
- 반복행의 경우 행 높이(`rowHeight`)와 최대 행 수(`maxRows`)가 0 이하가 아닌지도 함께 검사

**실패 메시지:**

- 필드 없음: `편집 미완료 — 필드가 없습니다.`
- 영역 겹침: `영역 겹침: {dataKey1} / {dataKey2}`
- 데이터 키 중복: `데이터 키 중복: {dataKey}`
- 여러 오류는 쉼표로 연결하여 표시
- 오류 사유는 DB에 저장하지 않으며 새로고침 시 사라짐

### 4.8 읽기 전용

- 조건: `status != draft` 또는 `printedCount > 0`
- 제한 항목
  - 양식명 변경
  - 인쇄 부수 변경
  - 필드 추가·복사·붙여넣기·삭제
  - 필드 이동·크기 조절
  - 속성 및 옵션 변경
  - AI 자동 추천
- 조회, 화면 이동, 확대·축소, 데이터 테스트는 가능
- 인쇄 이력이 없으면 `[편집 중]` 클릭으로 즉시 편집 상태 복귀(검사 없이 바로 전환)

### 4.9 인쇄 이력 잠금

- 조건: `printedCount > 0`
- SOBP가 1건이라도 발급되면 편집 중 상태로 복귀 불가
- `[편집 중]` 버튼 비활성
- 툴팁: `이미 인쇄된 양식은 다시 편집할 수 없습니다 — 복제해서 새로 만드세요.`
- 수정이 필요하면 `[⧉ 복제해서 편집]` 사용
  - 필드, PDF, 반복행, Excel 템플릿을 복사한 새 `draft` 생성
  - 새 양식 편집기로 이동

## 6. 구현 참고

- PDF 업로드 최대 크기: 20MB(서버에서 base64 길이로 강제)
- 필드 위치와 크기는 페이지 기준 0~1 정규화 좌표로 저장
- AI 추천 신뢰도 임계값 0.4, 최소 박스 면적 임계값 0.0003은 서버 상수(`MIN_CANDIDATE_CONFIDENCE`, `MIN_CANDIDATE_BOX_AREA`)로 고정돼 있으며 화면에서 조정할 수 없음
- AI 추천 결과는 자동 확정하지 않으며 사용자 검수 필요
- 인쇄 가능 전환 실패 사유는 현재 요청에만 표시하고 DB에 저장하지 않음
- 표 형태 데이터는 개별 필드 + 데이터 키 수동 접미사(`.01`,`.02`)로 표현한다. 기존 반복행 데이터가 있는 양식은 이 화면에서 편집·해제 가능(§4.4a)
- 실제 SOBP·NCode 출력 정책은 FRM-01 다운로드 명세 참고
