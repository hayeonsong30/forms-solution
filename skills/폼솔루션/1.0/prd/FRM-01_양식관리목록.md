## 1. 화면 개요

- **화면 ID**: `FRM-01`
- **화면 이름**: 양식 관리 목록
- **메뉴 경로**: 양식 관리
- **대상 사용자**: 양식 생성·관리 담당자
- **비즈니스 목적**: 양식을 검색·필터링하고 생성, 다운로드, 복제, 삭제한다.
- **편집 진입**: 목록 행 클릭 시 양식 편집기(FRM-02)로 이동

## 2. 주요 사용자 흐름 (Happy Path)

1. `양식 관리` 메뉴 진입 후 수정일 최신순으로 정렬된 전체 양식 확인
2. 검색어 또는 상태 탭으로 원하는 양식 조회
3. 목록 행 클릭하여 양식 편집기(FRM-02) 진입
4. 인쇄 가능한 양식은 설정 부수 확인 후 PDF 또는 ZIP 다운로드
5. 기존 양식을 수정해야 하는 경우 복제하여 새 편집본 생성
6. 발행 이력이 없는 양식은 확인창을 거쳐 삭제

## 3. 화면 구성

### 3.1 상단 영역

- 페이지 제목: `양식 관리`
- `[+ 빈 양식 업로드]` 클릭 시 새 양식 생성 후 FRM-02로 이동
  - 이름: `이름 없는 양식`
  - 상태: `draft`
  - 페이지 수: 1
  - 조직 목록 미로딩 또는 생성 처리 중에는 클릭 무시
  - 생성 처리 중 버튼 비활성
  - 양식명 입력 팝업은 노출하지 않음
  - 생성 API 실패 시 현재 화면 유지

### 3.2 요약 카드

- **전체 양식**: 전체 양식 수
- **편집 중**: `status = draft`인 양식 수
- **발급된 SOBP**: 양식별 `printedCount × pageCount` 합계
  - 문서 1부는 페이지별로 SOBP를 사용하므로 발급 부수에 페이지 수를 곱함
  - 예: 3페이지 양식 10부 발급 시 SOBP 30개로 계산

### 3.3 검색·필터

- 검색창: 양식 ID 또는 양식명 기준 실시간 검색
  - Placeholder: `양식 ID·양식명 검색`
  - 대소문자 구분 없음
  - 입력값이 ID 또는 양식명 일부에 포함되면 노출
- 상태 탭: `전체` / `편집 중` / `인쇄 가능` / `발급 완료`
- 서버 재조회 없이 현재 목록에서 필터링

| 탭 | 노출 조건 |
|---|---|
| 전체 | 모든 양식 |
| 편집 중 | `status = draft` |
| 인쇄 가능 | `status = printable`이고 `printedCount < printCopies` |
| 발급 완료 | `status = printable`이고 `printedCount >= printCopies` |

### 3.4 양식 목록

- 정렬: 수정일(`updatedAt`) 최신순
- 컬럼: NO, ID, Name, Owner, 페이지, 설정 부수, 상태, 등록일, 수정일, 작업
- ID: 앞 8자리만 표시
- Owner: `데모 관리자`, `demo-admin@neolab.local` 고정 표시
- 페이지: 양식 1부를 구성하는 페이지 수(`pageCount`)
- 설정 부수: 발급 예정 부수(`printCopies`), `{n}부` 형식
- 등록일·수정일: 한국어 로케일 날짜 형식으로 표시
- 행 클릭 또는 Enter/Space 입력 시 FRM-02로 이동
- 작업 버튼 클릭 시 행 이동 동작 제외
- 조회 결과가 없으면 `등록된 양식이 없습니다.` 표시
- `[문서 조회 →]` 클릭 시 문서 조회(`/documents`)로 이동

**상태 표시:**

| 표시 상태 | 조건 | 표시 |
|---|---|---|
| 편집 중 | `status = draft` | 회색 |
| 인쇄 가능 | `status = printable`이고 미발급 부수 존재 | 초록 |
| 발급 완료 | `status = printable`이고 설정 부수 전체 발급 | 회색 |

**작업 버튼:**

- **다운로드**
  - `draft`: 비활성
  - `printable`: 활성
  - 발급 완료 상태에서는 `다시 받기`로 표시
  - 클릭 시 다운로드 설정 팝업 노출
- **복제**
  - 현재 버전의 필드, 선택지, 반복행, PDF, Excel 템플릿을 복사
  - 새 양식명: `{기존 양식명} (복사본)`
  - 새 양식 상태: `draft`
  - 설정 부수와 발급 이력은 복사하지 않음 — 새 양식의 설정 부수는 원본 값과 무관하게 항상 기본값 1부터 다시 시작
  - 생성 후 FRM-02로 이동
  - 요청 처리 중 해당 복제 버튼 비활성
- **삭제**
  - `printedCount > 0`: 비활성
  - 비활성 툴팁: `이미 발행된 문서가 있어 삭제할 수 없습니다.`
  - 활성 상태에서 클릭 시 `"{양식명}" 양식을 삭제할까요? 되돌릴 수 없습니다.` 확인창 표시
  - 성공 시 목록 갱신
  - 발행 문서가 있으면 삭제 버튼 비활성화
  - 서버가 `409 TEMPLATE_HAS_DOCUMENTS`로 차단한 경우(버튼이 비활성화된 이후에도 다른 경로로 문서가 먼저 발급되는 경합 상황 등) `이미 발행된 문서가 {건수}건 있어 삭제할 수 없습니다.` 표시
  - 그 외 실패 시 `양식 삭제 실패` 표시

### 3.5 다운로드 설정 팝업

- 진입: `다운로드` 또는 `다시 받기` 클릭
- 설정 부수: `설정 부수: {n}부` 표시
- 설정 부수는 FRM-02에서 지정한 발급 계획값
- 청사진 모드: on/off 설정
- NCode 점 크기: 0.1~2.0, 0.1 단위 설정
- 설정값은 `localStorage(formsolution.printSettings)`에 저장
- `[기본값으로 재설정]` 클릭 시 청사진 모드 on, 점 크기 0.5로 복원
- `[닫기]` 클릭 시 상태 변경 없이 팝업 닫기
- 발급/재발급 처리 중에는 `[닫기]` 버튼도 함께 비활성

> **미구현**: 청사진 색상 변환, 점 크기 적용, 실제 SOBP·NCode 패턴 삽입. 현재 설정은 UI와 브라우저 저장에만 반영되며 다운로드 파일은 원본 PDF다.

**공통 정책:**

- 앱에서 프린터를 직접 제어하지 않고 PDF 또는 ZIP 파일만 제공
- 다운로드 한 번으로 설정 부수 전체 처리
- SOBP가 1건이라도 발급되면 양식 편집과 설정 부수 변경 불가

#### 미발급 부수가 있는 경우

- 주 버튼: `[⬇ 다운로드]`
- 처리 중에는 버튼 라벨이 `다운로드 준비 중…`으로 전환
- 남은 부수(`printCopies - printedCount`) 전체를 한 번에 발급
- 1부: PDF 다운로드
- 2부 이상: 동일한 원본 PDF를 부수별 파일로 구성하여 ZIP 다운로드
- 성공: 목록 갱신 후 팝업 닫기
- 발급 실패:
  - 문서 레코드와 발급 수 변경 없음
  - `발급에 실패했습니다. 다시 시도해주세요.` 표시
  - 팝업을 유지하며 재시도 허용
- 발급 성공·파일 다운로드 실패:
  - 발급 수는 즉시 반영
  - 버튼을 `[다시 받기]`로 전환
  - `SOBP는 발급됐지만 파일 다운로드에 실패했습니다. 아래 '다시 받기'로 다시 받아주세요.` 표시
  - 팝업을 유지하고 중복 발급 차단

#### 설정 부수를 모두 발급한 경우

- 주 버튼: `[🔁 다시 받기]`
- 처리 중에는 버튼 라벨이 `다시 받는 중…`으로 전환
- 신규 SOBP를 발급하지 않고 설정 부수만큼 원본 파일 재다운로드
- 안내 문구: `이미 설정 부수만큼 전부 발급됐습니다. 새로 발급하지 않고 같은 내용을 다시 받습니다.`
- 성공: 팝업 닫기
- 성공 시 신규 문서가 생성되지 않으므로 목록을 갱신하지 않음
- 실패: `다시 받기에 실패했습니다. 잠시 후 다시 시도해주세요.` 표시 후 팝업 유지

## 4. 상태별 변화

### FRM-01:편집중

- 조건: `status = draft`
- 표시: `편집 중`, 회색
- 다운로드 버튼 비활성
- 신규 양식의 기본 상태
- FRM-02에서 구조 검사 완료 시 인쇄 가능 상태로 전환
- 발급 이력이 없는 경우 FRM-02에서 인쇄 가능 상태를 다시 편집 중으로 전환 가능

### FRM-01:인쇄가능

- 조건: `status = printable`이고 미발급 부수 존재
- 표시: `인쇄 가능`, 초록
- 다운로드 버튼 활성
- 목록 화면에서는 상태 변경 불가
- SOBP 발급 후 편집 중 상태로 복귀 불가
- 수정이 필요하면 양식을 복제하여 새 `draft` 생성

### FRM-01:발급완료

- 조건: `status = printable`이고 `printedCount >= printCopies`
- 상태를 `발급 완료`로 표시
- 다운로드 버튼을 `다시 받기`로 표시
- 다시 받기 시 신규 SOBP 미발급
- `발급 완료`는 DB 상태가 아닌 화면 전용 파생 상태

### FRM-01:삭제불가

- 조건: `printedCount > 0`
- 삭제 버튼 비활성
- 마우스오버 시 삭제 불가 사유 표시
- 클라이언트와 서버에서 삭제 차단
- 발급 완료 여부와 관계없이 발행 문서가 1건 이상이면 적용
